# تقویم هفتگی شمسی

یک اپ وب شبیه گوگل کلندر با تمرکز روی نمای هفتگی، تاریخ شمسی کامل، کارت‌های
قابل کشیدن (drag & drop) برای برنامه‌ریزی کارها، یادآور ساده، و یک دستیار
چت فارسی که متن آزاد رو به کارهای زمان‌بندی‌شده تبدیل می‌کنه.

## امکانات

- **نمای هفتگی** (شنبه تا جمعه) با گرید ۲۴ ساعته، تاریخ شمسی
- **ستون کارهای برنامه‌ریزی‌نشده** در کنار تقویم؛ کارت‌ها رو می‌کشی و روی
  روز/ساعت موردنظر در تقویم رها می‌کنی — ساعت به‌صورت خودکار از محل رها شدن
  محاسبه می‌شه
- **کلیک روی هر نقطه‌ی خالی تقویم** برای ساخت سریع یه کار در همون روز/ساعت
- **یادآور** ساده (اعلان مرورگر - Notification API) چند دقیقه قبل از هر کار
- **دستیار چت فارسی**: متنی مثل «ساعت ۵ میرم گل‌فروشی» یا «فردا ساعت ۹ جلسه و
  ساعت ۲ دندون‌پزشکی» رو می‌نویسی، مدل هوش مصنوعی رایگان (از طریق OpenRouter) کارها رو تشخیص
  می‌ده و به‌صورت کارت‌های پیشنهادی نشون می‌ده؛ با یک کلیک به تقویم اضافه
  می‌شن

## استک فنی

- **Next.js 16** (App Router) + TypeScript + Tailwind CSS 4
- **پایگاه‌داده**: SQLite با ماژول built-in خود Node.js (`node:sqlite`) —
  بدون نیاز به هیچ سرویس یا باینری خارجی
- **تبدیل تاریخ**: کتابخانه‌ی `jalaali-js`
- **هوش مصنوعی**: تماس مستقیم با OpenRouter API (مدل‌های :free رایگان) از یک
  API Route سمت سرور (کلید API هرگز به مرورگر ارسال نمی‌شه)
- فونت فارسی Vazirmatn به‌صورت لوکال (بدون وابستگی به Google Fonts)

## اجرای محلی

```bash
npm install
cp .env.example .env.local
# OPENROUTER_API_KEY رو داخل .env.local بذار (رایگان از https://openrouter.ai/keys)
npm run dev
```

اپ روی `http://localhost:3000` بالا میاد.

## متغیرهای محیطی

| متغیر | الزامی؟ | توضیح |
|---|---|---|
| `OPENROUTER_API_KEY` | برای بخش چت بله | کلید API رایگان از OpenRouter (https://openrouter.ai/keys) |
| `OPENROUTER_MODEL` | خیر | پیش‌فرض `meta-llama/llama-3.3-70b-instruct:free` |
| `DB_PATH` | خیر (توصیه‌شده در پروداکشن) | مسیر کامل فایل SQLite، مثلاً `/data/app.db`. اگر ندی، کنار پوشه‌ی اجرا یک پوشه‌ی `data` می‌سازه. |

## دیپلوی روی Railway

۱. یک پروژه‌ی جدید در [Railway](https://railway.app) بساز و ریپوی گیت‌هاب
   این پروژه رو وصل کن (یا مستقیم آپلود کن).
۲. Railway به‌صورت خودکار `npm run build` و `npm run start` رو اجرا می‌کنه.
   چون از `output: "standalone"` استفاده شده، بهتره Start Command رو این‌طور
   ست کنی تا سرور استاندالون واقعی اجرا بشه:
   ```
   node .next/standalone/server.js
   ```
   و یک مرحله‌ی build سفارشی برای کپی کردن `public` و `.next/static` داخل
   `.next/standalone` لازمه — اسکریپت آماده‌اش در `scripts/prepare-standalone.sh`
   هست؛ کافیه در تنظیمات Railway دستور build رو به این تغییر بدی:
   ```
   npm run build && bash scripts/prepare-standalone.sh
   ```
۳. در بخش **Variables** پروژه، `OPENROUTER_API_KEY` رو اضافه کن. برای
   پایدار موندن دیتای تقویم بین دیپلوی‌ها، یک **Volume** به مسیر مثلاً
   `/data` وصل کن و متغیر `DB_PATH=/data/app.db` رو هم ست کن — وگرنه با هر
   دیپلوی جدید، دیتای قبلی از بین میره.
۴. پورت رو Railway خودش با متغیر `PORT` مدیریت می‌کنه؛ نیازی به تنظیم دستی
   نیست.

### نکته درباره‌ی Cloudflare
اگه ترجیح میدی روی Cloudflare (Pages/Workers) ببری، بدون تغییرات معماری
(به‌خصوص `node:sqlite` که یک ماژول Node واقعیه، نه سازگار با Workers) کار
نمی‌کنه؛ باید لایه‌ی دیتابیس رو به Cloudflare D1 و بخش زمان‌بندی/چت رو به
Workers منتقل کنی. Railway برای این پروژه بدون هیچ تغییری کار می‌کنه، برای
همین به‌عنوان مسیر پیش‌فرض انتخاب شده.

## نکات و محدودیت‌های نسخه‌ی فعلی (MVP)

- `node:sqlite` هنوز به‌صورت رسمی «آزمایشی» (experimental) در Node.js
  علامت‌گذاری شده؛ برای استفاده‌ی شخصی/تیم کوچیک کاملاً قابل‌اعتماده، ولی
  اگه بعداً نیاز به مقیاس بزرگ‌تر یا چند ری‌پلیکا داشتی، بهتره به Postgres
  (مثلاً با Prisma) مهاجرت کنی.
- یادآورها با Notification API مرورگر کار می‌کنن، یعنی تا وقتی تب اپ باز
  نباشه، اعلان نمی‌بینی. برای یادآور واقعی حتی وقتی اپ بسته‌ست، قدم بعدی
  اضافه کردن Push Notification (Service Worker) یا ایمیل/پیامک هست.
- در حال حاضر تشخیص کارها با هوش مصنوعی، پیام رو بدون تاریخچه‌ی مکالمه
  می‌فرسته (هر پیام مستقل پردازش می‌شه).
- احراز هویت کاربر وجود نداره؛ همه‌ی کارها در یک دیتابیس مشترکن (مناسب
  استفاده‌ی شخصی).

```
src/
  app/
    page.tsx              صفحه‌ی اصلی (ترکیب سایدبار + تقویم + چت)

    api/chat/               تشخیص کار از متن فارسی با OpenRouter

    Sidebar.tsx, TaskCard.tsx        کارت‌های برنامه‌ریزی‌نشده
    TimeGridView.tsx, MonthView.tsx  نمای روز/هفته (گرید ساعتی) و نمای ماه

    TaskEditorModal.tsx              فرم ساخت/ویرایش کار
    ChatPanel.tsx                    پنل دستیار چت
  lib/
    jalali.ts        توابع تبدیل و فرمت تاریخ شمسی
    db.ts             لایه‌ی دیتابیس SQLite
    gridConfig.ts     ثابت‌های چیدمان گرید هفتگی
```
